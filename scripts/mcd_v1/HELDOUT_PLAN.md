# 第二轮：新案例验证
修改起点：服务器 main 的 fd20a17。独立实验目录固定到同一提交，并同步本轮未提交的实验代码。
原来的 10 个案例整体作为调参集排除，不仅排除已运行的 video/question。
本轮包含 46 个新案例，89 道冲突视频题和 54 道去重正常视频题，共 143 个单位。
每个冲突视频的每个问题分别计数；正常视频按路径+问题去重。只纳入有唯一可用正常对照的原始案例，
不按历史答案筛选；变体、未准备好或人工拒绝的视频不纳入。待人工审核视频可纳入，结论需核验。
参数：lambda=0/0.2/0.3，beta=0.1，4fps，512 tokens，thinking off，GPU 1。共429份回答。
同一模型复用，lambda=0每题仅生成一次。参考答案不进入模型输入。

在原来的 mcd-sweep tmux 会话里执行：
```bash
cd /home/ma-user/workspace/Video-Knowledge-Conflict-mcd
bash scripts/mcd_v1/run_heldout.sh
```
输出位于该独立目录的 results/mcd_v1/heldout_physics_v1/。
report.md 对比回答；report.json 保留问题、参考、原始回答、角色和配对关系；
summary.json 只统计生成状态与耗时，不是正确率。
重跑相同命令可续跑，已有失败文件也保留，检查后移走该文件才能重试。
原调参报告保留，但代码指纹已改变，不能用新代码续跑旧扫描目录。

结果评估：
1. 冲突题和正常题分别统计，format_fallback依据正文评估，同时单独记录格式异常。
2. 最终答案与参考的一致性、正文解释错误分别记录；未看视频的判定明确为初步结果。
3. 按同题lambda=0配对统计错转对、对转错；正常对照仅按去重单位统计，不因多个冲突配对重复计权。
4. 初步偏差与歧义问题保留审计记录；若核查后需剔除，报告全部样本与剔除后两套结果。
5. 新样本验证完成前不继续调参数；不把调参集与本轮结果混算。
